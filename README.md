# rea_agent

A satellite crop-monitoring app (**Fieldwise**) built after reverse-engineering a commercial farm app with [REA](https://github.com/morluto/rea).

- [FEATURES.md](FEATURES.md): what Fieldwise does
- [RUNNING.md](RUNNING.md): how to run it
- [fieldwise/](fieldwise/): the app (React, Vite, MapLibre, Three.js)
- [tools-scripts/](tools-scripts/): helper scripts used during the analysis
- `rea-tool/`: REA itself, linked as a git submodule

Quick start:

```bash
cd fieldwise
npm install
npm run dev     # http://127.0.0.1:5180
```
